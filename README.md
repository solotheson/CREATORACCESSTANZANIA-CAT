# Creator Access Tanzania (CAT)

A mobile-first streaming platform MVP for Tanzanian comedy, documentaries, lifestyle, and real-life stories.

## What is included

- Responsive viewer experience for comedy and documentary discovery
- Video watch modal with like and share actions
- Search across sample video content
- Creator discovery and creator application flow
- Login and join-entry flows
- Sponsorship placement and sample viewer metrics

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Production roadmap

The current release is a front-end prototype. The next phase should add Next.js, a Node/NestJS API, PostgreSQL, secure authentication, object storage and video transcoding/CDN delivery.
